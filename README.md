# نظام إدارة المختبرات الطبية الذكية | LabCore Pro LIS

نظام ويب متكامل واحترافي لإدارة معامل ومختبرات التحاليل الطبية (Laboratory Information System - LIS) يعمل بواجهة عربية كاملة داعمة لـ RTL مع الوضعين الليلي والنهاري (Dark / Light Mode)، مبني لتغطية دورة العمل الكاملة داخل المختبر من لحظة استقبال المريض وحتى اعتماد وطباعة التقرير الطبي الرسمي.

---

## 🌟 الميزات والموديولات الرئيسية

1. **لوحة التحكم والمؤشرات الحية (Dashboard):**
   - إحصائيات فورية وتفاعلية: عدد مرضى وحالات اليوم، التحاليل قيد الفحص، التحاليل المعتمدة الجاهزة للتسليم، مقبوضات اليوم النقدية، وإجمالي مديونيات المرضى.
   - سجل زيارات وعينات اليوم مع شارات الحالة المخبرية والوصول السريع للنتائج والطباعة.

2. **الاستقبال وحجز الزيارات والفوترة (Reception & Orders):**
   - **التعرف التلقائي على المريض السابق:** بمجرد كتابة رقم الهاتف، يتعرف النظام فوراً على المريض ويسترجع بياناته تلقائياً ويعرض سجل تحاليله وزياراته السابقة.
   - اختيار التحاليل والباقات مع احتساب آلي متزامن للمجاميع والخصومات والمدفوع والمتبقي.
   - إصدار إيصال استلام فوري مزود بشريط باركود رقمي دقيق ونوع أنبوبة السحب المطلوبة.

3. **دليل التحاليل الطبية والباقات التخصصية (Tests & Packages Catalog):**
   - قاعدة بيانات سريرية واقعية تضم أكثر من 27 فحصاً تفصيلياً (CBC كامل بـ 15 متغيراً، سيولة الدم PT-INR و aPTT، وظائف الكلى، وظائف الكبد، السكر الصائم والتراكمي مع eAG، الدهون والنسبة التراكمية، الهرمونات TSH/FT4/FT3، الفيتامينات ومخزون الحديد، البول الكامل).
   - توضيح ألوان وتصنيفات أنابيب السحب (EDTA بنفسجي، أنبوبة جل صفراء، سترات زرقاء وسوداء، فلوريد رمادية، وكوب بول معقم).
   - 6 باقات فحص شاملة ومعتمدة (الفحص التنفيذي VIP، السكري، الكبد والكلى، الأنيميا وتساقط الشعر، ما قبل الزواج، وما قبل العمليات).

4. **إدخال ومراجعة النتائج والاعتماد الطبي (Lab Results & Validation):**
   - شاشة إدخال لفني المعمل مع محرك تقييم فوري ومباشر (Live High / Low / Normal Flags).
   - دعم المدى المرجعي الطبيعي المتغير بحسب جنس المريض (ذكور / إناث).
   - دورة الاعتماد الرسمي لمدير المعمل (Approve & Validate) وقفل النتائج لمنع التعديل مع إمكانية فك الاعتماد الإداري.

5. **التقرير الطبي الرسمي المعياري A4 وإشعارات واتساب (Medical Report & WhatsApp):**
   - قالب طباعة قياسي A4 معد للطباعة المباشرة أو الحفظ كملف PDF يحتوي على ترويسة المعمل الرسمية، بيانات المريض، الباركود، جدول النتائج مع القيم المرجعية والتقييمات، ملاحظات الاستشاري، التوقيع، والختم الدائري المعتمد.
   - **زر إرسال واتساب مباشر:** إشعار المريض بجاهزية النتيجة بنقرة واحدة برسالة عربية رسمية.

6. **إدارة الخزينة والمصروفات والتعاقدات (Finance & Contracts):**
   - تحصيل متبقيات المرضى وتسوية المديونيات فورياً مع أزرار عالية التباين والوضوح 100%.
   - تسجيل وتصنيف مصروفات المعمل (كيماويات وكواشف، مستلزمات سحب، صيانة أجهزة، رواتب، إيجار).
   - متابعة جهات التعاقد والتأمين (نقابة المهندسين، نقابة الأطباء، متلايف، أكسا، قطاع البترول).

7. **إعدادات وهوية المختبر (Lab Settings):**
   - تخصيص اسم المعمل (عربي وإنجليزي)، رقم الترخيص، أسماء وألقاب الإدارة الطبية، وسائل الاتصال، العنوان، ونص التذييل القانوني.
   - تنعكس التعديلات لحظياً في ترويسة التقارير الطبية A4، وإيصالات الاستقبال، والشريط الجانبي.

8. **التخزين الفوري والنسخ الاحتياطي (Persistence & Backup):**
   - حفظ ومزامنة فورية لكافة العمليات في `localStorage`.
   - أزرار تصدير واستيراد نسخة احتياطية كاملة بصيغة JSON لحماية البيانات من الضياع وسهولة نقلها.

## 🚀 طريقة التشغيل

التطبيق مصمم ليعمل كـ Single Page Application دون الحاجة لتثبيت خوادم معقدة:

1. افتح المجلد في أي متصفح، أو شغل خادماً محلياً سريعاً عبر بايثون:
   ```bash
   python -m http.server 5500
   ```
2. افتح الرابط في المتصفح:
   ```text
   http://localhost:5500
   ```

## 🛠️ المعمارية والتقنيات المستخدمة

- **Frontend:** Vanilla JS (ES6+ Classes), Modern CSS3 (Variables, Dark/Light tokens, Flexbox/Grid).
- **Icons:** Lucide Icons (SVG).
- **Fonts:** Cairo (Arabic Typography), JetBrains Mono (Medical Barcodes & Numbers).
- **Print Engine:** CSS `@media print` optimized for A4 300 DPI Medical Standards.
- **State Management:** Reactive Custom Store with Observer Pattern & LocalStorage Persistence.
